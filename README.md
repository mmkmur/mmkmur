## Security Labs & POCs

### [Entra-ID-PoC](./Entra-ID-PoC/)
Proof of concept for **Azure Entra ID B2B** (Guest user federation). Includes a Node.js web app using MSAL.js for OIDC authentication, guest invite flows, and a Postman collection for testing.

### [IAM-lab](./IAM-lab/)
Hands-on lab demonstrating **SAML 2.0 federation** between Keycloak (Identity Provider) and Azure Entra External ID (Service Provider). Includes Bicep infrastructure templates, Docker Compose for Keycloak, and a web app using MSAL.js.

### [api-security-lab](./api-security-lab/)
Lab exploring **API security** concepts including authentication, authorisation, and common vulnerability testing. Includes a Node.js API server and Postman collection.

### [secret-management-poc](./secret-management-poc/)
POC for **automated secret rotation** using Azure Key Vault, Event Grid, and Azure Functions. Demonstrates how to detect near-expiry secrets, trigger rotation, and notify downstream services.
